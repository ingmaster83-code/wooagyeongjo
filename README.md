# 우아경조사 (wooagyeongjo)

축의금·조의금·돌잔치·집들이·개업·승진·환갑칠순·입학졸업 경조사비 기준표, 관계별 가이드, 금액 계산기(JS), 봉투 쓰는 법, 청탁금지법 상한 정리 사이트(Python 정적 생성기, 데이터 파일 없음). https://wooagyeongjo.wooahouse.com

- 금액은 공식 통계가 없는 분야라 2026년 경조사비 설문(평균 축의금 약 9.8만 원·조의금 약 9.5만 원, 10만 원 최빈, 다음뉴스 '아무튼, 주말'×SM C&C)·청탁금지법 시행령·일반 가이드를 종합한 **통용 범위**다. 값은 `scripts/build_site.py` `EVENTS`/`RT` 딕셔너리에 있다(최소선·보통·가까운 사이, 단위 만원). 갱신 시 출처 링크(`SRC`)와 함께 수정.
- 계산기: 금액 단계(`STEPS`)에서 4·6만 원 제외, 결혼식은 식사 여부·호텔 여부 반영, 받은 금액이 있으면 그 이상으로 맞춤.
- 청탁금지법: 경조사비 5만 원(화환·조화 10만 원), 식사 5만 원(2024-08-27 상향) — 개정 시 `/청탁금지법/` 페이지 수정.
- Actions: push 시 빌드·배포. 네이버 소유확인 토큰은 `scripts/common.py` `NAVER_TOKEN`.
